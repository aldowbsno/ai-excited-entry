# Event Horizon: The First Spark

A deterministic, procedural Python image entry for make.fun's **Make the AI judge excited** competition. It renders a vivid cosmic detonation with a high contrast focal core, cool nebula structure, and a silhouetted observer for scale.

## Run

```bash
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program uses only Python's standard library and writes `out/entry.png` deterministically.
